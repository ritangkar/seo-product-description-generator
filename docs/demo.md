# Portfolio Demo

**Demo level:** 1 — client-side, fully deterministic.

`lab/demos/seo-product-description-generator.js` ports the full seven-stage
pipeline — attribute extraction, keyword analysis, tone-aware template
generation, SEO validation, factuality checking, and quality scoring — to
client-side JavaScript. A recruiter fills in a product's name, category,
brand, features, specifications and tone, and sees the identical
generated content, validation issues, and quality score this README
documents, live, with no backend call.

Try deliberately removing a feature or shortening the input to see the
SEO validation and quality score respond in real time — that responsiveness
is the point of the demo, more than any single generated example.
